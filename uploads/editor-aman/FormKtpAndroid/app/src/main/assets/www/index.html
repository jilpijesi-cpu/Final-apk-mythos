7–12: Lahir (+40 Wanita)
XXXX
Digit 13–16: Nomor Urut Pendaftaran

Optimasi Khusus Mobile

  • Tata letak 1 kolom penuh maks 430px dengan navigasi bawah (*bottom tab bar*) ramah jempol.
  • Input & tombol bertarget sentuh minimal 48px dengan ukuran teks 16px agar iOS tidak *auto-zoom*.
  • Keyboard numerik otomatis (inputmode="numeric") untuk NIK, RT, dan RW.
  • Modal konfirmasi bergaya *bottom sheet* serta tombol lompat cepat ke pratinjau kartu.
